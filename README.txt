A.S.D Motors Nigeria — Static Website

This folder contains the full website as plain HTML, CSS, and JavaScript.
No build tools or server required.

HOW TO USE:
  1. Open any of the HTML files in a web browser to preview locally:
       - index.html       (Home)
       - services.html    (Services)
       - about.html       (About)
       - testimonials.html (Reviews)
       - contact.html     (Visit Us)
  2. To publish online, upload the ENTIRE folder to any static host
     (Netlify, Vercel, GitHub Pages, cPanel, S3, etc.).

FILES:
  *.html       - Pages
  styles.css   - All styling (design tokens, layouts, animations)
  script.js    - Mobile menu, scroll header, form, testimonials carousel
  assets/      - Images

Fonts are loaded from Google Fonts (Cormorant Garamond + Inter).
Icons are inline SVG — no external icon library needed.
